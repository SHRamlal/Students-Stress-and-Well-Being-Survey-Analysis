# Students-Stress-and-Well-Being-Survey-Analysis

Data Source: https://www.kaggle.com/datasets/ashutoshsingh22102/stress-and-well-being-data-of-college-students/data?select=Stress+Dataset.csv
An overall stress score was created which was deemed reliable. Indicators from previous documentation https://www.kaggle.com/datasets/mdsultanulislamovi/student-stress-monitoring-datasets) was used as a guide to group factors for analysis. However, due to low reliability measures, new factors were created using Factor Analysis to evaluate any themes in the dataset.

A linear regression model and Type II ANOVA tests were run to assess factors impacting stress in students.
